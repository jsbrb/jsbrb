# Hola, soy Javi

Soy desarrollador en **GDX Group**, en Valencia. Y esto que estás viendo —
**The North Code** — es mi marca personal. *North*, por el norte que me vio
nacer. *Code*, por lo que me apasiona.

Mi base es el backend Java: Spring Boot, APIs, bases de datos. Mi foco está
en las partes del oficio que la IA no puede hacer por nadie — entender el
problema, diseñar la solución y dejarla por escrito. Luego la IA ejecuta,
y yo dirijo.

Por eso trabajo con **Spec-Driven y Test-Driven Development**: las
especificaciones, la documentación y el testing dirigen el proyecto; no lo
adornan. Y cada proyecto lo organizo en hitos con decisiones ratificadas y
verificables (**ODD**), de modo que el plan evoluciona con el proyecto en
lugar de quedar en un documento muerto.

## Stack

Backend con Java + Spring Boot, también PHP y Python; PostgreSQL como base
de datos habitual. Frontend con Astro, TypeScript, React y Tailwind; NestJS
y Next.js cuando el proyecto lo pide. Prácticas: Spec-Driven Development,
TDD, ODD y testing con Vitest. Docker y GitHub Actions cuando toca.
La herramienta adecuada para cada trabajo, nunca tecnología por moda.
